# Vue语法

## v-for

Vue/UniApp 使用了 **虚拟 DOM (Virtual DOM)** 技术。当数据变化时，它会对比“新旧列表”的差异，然后只更新变动的部分。

假设你有一个列表 `[A, B, C]`，你想把它变成 `[A, C]`（删掉了 B）。

- **如果没有 key (`v-for` 默认行为)**： Vue 会采用“就地更新”策略。它发现第二个位置变成了 C，它会把第二个位置的 DOM 内容改成 C，然后把第三个位置删掉。这非常低效，且容易出 Bug（比如输入框里的文字没被清空）。
- **如果有 `:key="item.id"`**： Vue 会对比新旧节点：
  - A 的 key 没变 -> 复用 DOM。
  - B 的 key 不见了 -> 删除 B 的 DOM。
  - C 的 key 还在 -> 移动 C 的 DOM 位置（如果需要）。
  - **结果**：性能最高，且状态保留正确。
