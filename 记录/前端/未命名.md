## v-for

Vue/UniApp 使用了 **虚拟 DOM (Virtual DOM)** 技术。当数据变化时，它会对比“新旧列表”的差异，然后只更新变动的部分。

假设你有一个列表 `[A, B, C]`，你想把它变成 `[A, C]`（删掉了 B）。

- **如果没有 key (`v-for` 默认行为)**： Vue 会采用“就地更新”策略。它发现第二个位置变成了 C，它会把第二个位置的 DOM 内容改成 C，然后把第三个位置删掉。这非常低效，且容易出 Bug（比如输入框里的文字没被清空）。
- **如果有 `:key="item.id"`**： Vue 会对比新旧节点：
  - A 的 key 没变 -> 复用 DOM。
  - B 的 key 不见了 -> 删除 B 的 DOM。
  - C 的 key 还在 -> 移动 C 的 DOM 位置（如果需要）。
  - **结果**：性能最高，且状态保留正确。

# Flex 布局

## 一 Flex 布局介绍

### 1.1 什么是Flex布局

```python
# 1 布局的传统解决方案，基于盒状模型，依赖 display 属性 + position 属性 + float 属性。它对于那些特殊布局非常不方便，比如，垂直居中就不容易实现

# 2 Flex 是  Flexible Box 或 flexbox 的缩写，意为"弹性布局"，用来为盒状模型提供最大的灵活性

# 3 任何一个容器都可以指定为 Flex 布局。

.box{  
    display: flex;
}

# 4 行内元素也可以使用 Flex 布局。

.box{  
    display: inline-flex;
}
```



### 1.2 flex布局的好处

1 简单易懂：与传统的布局方式相比，Flex布局的语法和理解起来更加简单，容易上手。
2 弹性和自适应：Flex布局能够自动适应不同尺寸的屏幕，让页面更具有弹性。
3 等高布局：Flex布局可以方便地实现多列等高布局。
4 对齐和排序：Flex布局支持各种对齐方式，包括水平和垂直对齐，并且可以通过设置order属性对子元素进行排序。
5 可以与传统布局结合使用：Flex布局并不是完全取代传统的布局方式，它可以与传统布局方式结合使用，实现更灵活的布局效果




### 1.3 概念

```python
# 1  采用 Flex 布局的元素，称为 Flex 容器（flex container），简称"容器"。它的所有子元素自动成为容器成员，称为 Flex 项目（flex item），简称"项目"
	-容器和项目：container、item

# 2 容器默认存在两根轴：水平的主轴（main axis）和垂直的交叉轴（cross axis）
	-主轴和交叉轴：main axis、cross axis
# 3 主轴的开始位置（与边框的交叉点）叫做main start，结束位置叫做main end；交叉轴的开始位置叫做cross start，结束位置叫做cross end。
	-起始位置：
    	main start 主轴起始位置
        cross start 侧轴起始位置
    -结束位置：
    	main end 主轴结束位置
        cross start 侧轴结束位置
# 4 项目默认沿主轴排列。单个项目占据的主轴空间叫做main size，占据的交叉轴空间叫做cross size
	-主轴尺寸
    -侧轴尺寸
```

## 二 容器样式属性(6个)

1 flex-direction：决定主轴的方向。
2 flex-wrap：如果一条轴线排不下，如何换行。
3 flex-flow：flex-direction 属性和 flex-wrap 属性的简写属性。
4 justify-content：定义项目在主轴	上的对齐方式。
5 align-items：定义项目在交叉轴上如何对齐。
6 align-content：定义了多根轴线的对齐方式。如果项目只有一根轴线，该属性不起作用。




### 2.1 flex-direction

```python
# 1 flex-direction属性决定主轴的方向（即项目的排列方向）
# 2 有4个值（如下图）
row（默认值）：主轴为水平方向，起点在左端。
row-reverse：主轴为水平方向，起点在右端。
column：主轴为垂直方向，起点在上沿。
column-reverse：主轴为垂直方向，起点在下沿。

# 3 强调：使用 flex-direction属性后，因为主轴的位置发生了改变，使用和主轴或交叉轴有关的属性之前一定要确定好主轴的位置
```

### 2.4 justify-content

```python
# 1 justify-content属性定义了项目在主轴上的对齐方式
# 2  6个值，具体对齐方式与轴的方向有关。下面假设主轴为从左到右
justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;
    
    flex-start（默认值）：左对齐
    flex-end：右对齐
    center： 居中

    space-evenly：项目与项目之间，项目与边框之间的间隔都相等
```

### 2.6 align-content属性

```python
# 1 align-content属性定义了多根轴线的对齐方式。如果项目只有一根轴线，该属性不起作用。
	-允许项目换行【flex-wrap: wrap】，使用align-content属性的前提，否则align-content属性不生效
# 2 align-content: flex-start | flex-end | center | space-between | space-around | stretch; 6个值
    flex-start：与交叉轴的起点对齐。
```

### 2.7 align-items与align-content的差别

**Items** 是针对 **“每个个体”**：管的是每一行里的小弟怎么站。

**Content** 是针对 **“整堆内容”**：管的是所有行堆在一起怎么放。



<img src="D:\Code_Save\take-out\记录\前端\assets\image-20251220201428397.png" alt="image-20251220201428397" style="zoom:50%;" />

```html
<div class="container items-demo">
  <div class="box">1</div><div class="box">2</div>
  <div class="box">3</div><div class="box">4</div>
</div>

<div class="container content-demo">
  <div class="box">1</div><div class="box">2</div>
  <div class="box">3</div><div class="box">4</div>
</div>

<style>
  .container {
    display: flex;
    flex-wrap: wrap; /* 允许换行 */
    height: 300px;
    width: 200px;
    background: #eee;
    margin-bottom: 20px;
  }
  .box {
    width: 80px;
    height: 50px;
    background: coral;
    border: 1px solid white;
  }

  /* 重点在这里 */
  .items-demo {
    align-items: center; 
    /* 每一行在自己的空间内居中，行与行之间依然有分布 */
  }

  .content-demo {
    align-content: center; 
    /* 所有行被看作一个整体，挤在容器的正中间 */
  }
</style>
```



**视觉差异总结**

- **当你用 `align-items: center` 时**： 会发现容器被平均分成了两份（上下各一半），第一行的元素在上面那一半里居中，第二行的元素在下面那一半里居中。**行与行之间会有明显的空白间隔。**
- **当你用 `align-content: center` 时**： 会发现第一行和第二行**紧贴在一起**，然后整个“块”位居容器的最中间。**行与行之间没有额外的空白。**

## 小程序核心

### 尺寸单位和样式

在传统 Web 开发中，**px（CSS 像素）** 是一个固定单位，无法直接随屏幕宽度变化而自动伸缩，导致在不同分辨率的设备上难以实现等比缩放的布局。

微信小程序为了解决移动端屏幕尺寸碎片化的问题，提出了 **rpx (responsive pixel)** 这一**相对长度单位**。

`rpx` 将所有设备的屏幕宽度规定为 **750rpx**。小程序底层系统会根据当前设备的实际屏幕宽度，自动计算 `rpx` 与 `px` 之间的换算比例，从而实现一套代码在不同机型上的自适应渲染。”

### 盒子模型

![img](D:\Code_Save\take-out\记录\前端\assets\df5ae89838063ab25c5f722d0390e662.png)



#### 1. 核心解剖图：盒子的四个层级

想象你收到了一个快递包裹，盒子模型由内向外分为四层：

1. **Content (内容区)**
   - **实物**：这是盒子的核心，用来放文字、图片或子组件。
   - **大小**：默认由 `width` 和 `height` 决定。
   - **背景**：显示 `background-color` 或背景图。
2. **Padding (内边距)**
   - **填充物**：包裹在实物周围的泡沫纸，用于保护内容，把内容和边框隔开。
   - **特性**：**透明**，但会透出元素的背景色（除非使用了 `background-clip`）。
   - **交互**：点击 Padding 区域**会触发**点击事件（它属于盒子内部）。
3. **Border (边框)**
   - **纸箱壳**：包裹的最外层硬壳。
   - **特性**：可以有颜色、粗细、样式（实线/虚线）。
   - **层级**：如之前所说，背景色默认会延伸到 Border 下面。
4. **Margin (外边距)**
   - **安全距离**：快递箱放在地上时，与其他箱子保持的距离。
   - **特性**：**完全透明**，没有背景色。
   - **交互**：点击 Margin 区域**不会触发**该元素的点击事件（它是盒子外部的空间）。



#### 2. 关键分歧：两种盒子模式（标准的 vs 怪异的）

这是新手最容易晕的地方：**“我设置了 width: 100rpx，为什么盒子实际变大了？”**

这取决于 `box-sizing` 属性。

A. 标准盒子模型 (`content-box`) —— W3C 默认标准

- **逻辑**：你设置的 `width` 仅仅是 **Content** 的宽度。

- 公式：

  $$实际总宽度 = width + padding + border$$

- **后果**：如果你给一个 `100rpx` 的盒子加了 `10rpx` 的边框，它实际占位变成了 `120rpx`。这经常导致布局被撑破、换行。

B. 怪异盒子模型 (`border-box`) —— 现代开发推荐 🔥

- **逻辑**：你设置的 `width` 是 **整个盒子（Content + Padding + Border）** 的宽度。

- 公式：

  $$实际总宽度 = width$$

  (浏览器会自动压缩 Content 的空间来容纳 Padding 和 Border)

- **后果**：非常听话。说多大就多大，加边框也不会撑破布局。



#### 3. 一个特殊的现象：外边距合并 (Margin Collapse)

在盒子模型中，**垂直方向**的 Margin 有一个特殊的“物理定律”：

如果你有两个盒子上下排列：

- 盒子 A 下边距：`margin-bottom: 30rpx`
- 盒子 B 上边距：`margin-top: 20rpx`

问：它们中间隔多远？

答：不是 50rpx，而是 30rpx（取最大值）。

这就叫“合并”。（注：水平方向的 margin 不会合并，是相加的）。



#### 4. 综合代码演示 (WXSS)

```CSS
/* 推荐在 app.wxss 中全局设置，或者在组件最外层设置 */
view, text, image {
  /* 1. 开启“怪异盒子模型”，让布局更可控 */
  box-sizing: border-box;
}

.perfect-box {
  /* --- 尺寸控制 --- */
  /* 因为用了 border-box，这个盒子在屏幕上就严格占 300rpx */
  width: 300rpx;
  height: 300rpx;

  /* --- 装饰 --- */
  background-color: #fffae8; /* 浅黄背景 */
  
  /* --- 内部空间 (Padding) --- */
  /* 内容会被向内挤压，背景色会铺满这里 */
  padding: 20rpx;

  /* --- 边框 (Border) --- */
  /* 10rpx 的边框包含在 300rpx 宽度内，不会向外撑 */
  border: 10rpx dashed #ff9c6e;
  
  /* (进阶) 如果不想要背景色透出虚线边框，解开下面这行 */
  /* background-clip: padding-box; */

  /* --- 外部空间 (Margin) --- */
  /* 盒子外部留白，用来推开其他元素 */
  margin-bottom: 30rpx;
  
  /* --- 内容布局 --- */
  /* 盒子模型只管盒子本身，盒子里的东西怎么排由 Flex 决定 */
  display: flex;
  align-items: center;
  justify-content: center;
}
```

#### 总结

1. 盒子由内而外：**Content → Padding → Border → Margin**。
2. **Padding 和 Border** 属于盒子的一部分，**Margin** 属于盒子之外。
3. **背景色**默认会铺满 Content + Padding + Border。
4. 做开发时，强烈建议把所有元素设为 **`box-sizing: border-box`**，这样你的 `width` 设置才符合直觉（所见即所得）。
